# 🚀 Proyecto Vite + React + JSON Server

¡Bienvenido a tu proyecto moderno y ligero! 🌟 Aquí combinamos la potencia de **Vite**, la flexibilidad de **React**, la seguridad de **TypeScript** y la belleza de **Tailwind CSS + shadcn/ui**, con un backend simulado súper rápido usando **json-server**.

¿El objetivo? Que puedas desarrollar, probar y mostrar tu app sin complicaciones ni dependencias externas.

---

## 🎯 ¿Qué hay aquí?

- **Frontend** con Vite + React + TypeScript, para una experiencia ultra rápida y fluida.
- **Backend simulado** con `json-server`, para manejar datos como si tuvieras una API real.
- Configuración lista para correr en tu máquina con un solo comando por lado.

---

## 🛠️ Tecnologías principales

| Tecnología        | ¿Por qué la usamos?                                |
|-------------------|----------------------------------------------------|
| [Vite](https://vitejs.dev/)           | Inicio ultra rápido, recarga instantánea            |
| [React](https://reactjs.org/)         | Construcción de interfaces dinámicas y reactivas    |
| [TypeScript](https://typescriptlang.org/) | Seguridad y escalabilidad con tipado estático       |
| [Tailwind CSS](https://tailwindcss.com/) | Diseño rápido y personalizable con utilidades CSS   |
| [shadcn/ui](https://ui.shadcn.com/)  | Componentes UI accesibles y modernos                  |
| [json-server](https://github.com/typicode/json-server) | Backend falso, datos reales, sin complicaciones     |
